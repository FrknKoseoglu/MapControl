# Tab 4: Karşılama Sesi (Welcome Sound)

## Genel Bakış
* **Sekme İndeksi:** 4 (`TAB_WELCOME`)
* **Menü Adı (TR/EN):** Karşılama / Welcome
* **Builder:** `WelcomeSoundTabBuilder`
* **Kök View:** `ScrollView` / `LinearLayout`

## Arayüz Hiyerarşisi
1. **Karşılama Efekti Kartı:**
   * Araç açılışında özel ses oynatma açma/kapatma tercihi.
   * Ses dosyası seçici (Dahili hafıza veya USB üzerinden WAV/MP3).
2. **Önizleme Kontrolleri:**
   * "Sesi Dinle" / Test oynatma düğmesi.
   * Ses seviyesi ayarı.
